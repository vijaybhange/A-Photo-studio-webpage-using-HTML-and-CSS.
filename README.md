# Photo Studio - One Page

A simple one-page Photo Studio design created using HTML and CSS for frontend practice.

## 📌 About the Project

This is a single-page Photo Studio project created to practice and improve my CSS skills.

The project focuses on creating a clean visual layout and applying different CSS concepts to style the page.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Highlights

- One-page layout
- Photo Studio themed design
- Navigation section
- Hero section
- Image-based sections
- Custom CSS styling
- Hover effects
- Flexbox and positioning

## 🎯 Purpose

This project was created as a CSS practice project to strengthen my understanding of:

- Flexbox
- Positioning
- Spacing and alignment
- Typography
- Colors and backgrounds
- Hover effects
- Page layout and styling

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation or dependencies are required.

## 📚 Learning Outcome

This project helped me gain practical experience in structuring a webpage with HTML and creating its visual design using CSS.
